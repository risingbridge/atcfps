# ATC Flow Board (reimagined)

The from-first-principles successor to the strip board — see
`../docs/reimagined.md` for the concept and `../PLAN.md` (Reimagined track)
for the phases.

```
npm install
npm run dev      # dev server; open the printed URL + /atcfps/reimagined/
npm test
npm run lint
npm run build    # → ../dist/reimagined (run the root build first)
```

Deployed at https://risingbridge.github.io/atcfps/reimagined/ by the root
workflow. Local-only: same CSP plugin and audit as the main app.
